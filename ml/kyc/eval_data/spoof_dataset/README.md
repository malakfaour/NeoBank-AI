# Real spoof-evaluation fixtures

Drop 5–10 images per class here as a useful starting set:

- `live/`: a genuine live selfie captured directly by the camera.
- `printed_photo/`: a photo of that selfie printed on paper and photographed.
- `screen_replay/`: a photo of that selfie displayed on a screen.

Use consented images and keep the same subject represented across the three
classes where possible. Do not add generated placeholders or scratch files.
Run the evaluator against this folder after adding real captures.
